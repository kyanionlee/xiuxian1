# 《御剑问仙 · 山海纪》开发交接手册

> 给接手开发的 AI（Claude、Codex 等）与作者本人。**开始任何任务前先读完本文件和 `README.md`。**
> 最后更新：v1.6.3（Claude）。本文件路径固定为 `docs/handbook.md`（文件名保持英文，避免日文 / 中文 Windows 解压乱码；`docs/` 下新增文件也请用英文名）。

## 1. 项目一句话

浏览器修仙 roguelike：自动攻击 + 走位的即时战斗，加上三章路线图、职业、装备、奇遇、故人与跨轮回剧情。发布在 GitHub Pages：https://kyanionlee.github.io/xiuxian1/ ，主要玩家是中国大陆的朋友，以 iPhone Safari、安卓自带浏览器为主。

## 2. 硬性约束（不要违反）

1. **国内可访问**：不得引入任何外部网络依赖（外部字体、CDN、统计、后端）。所有资源放在本仓库。
2. **只改源码，不手改成品**：根目录 `index.html` 由 `node src/build.cjs` 生成。只改成品，下次构建就会丢失。
3. **存档兼容**：存档键 `yjwx-save-stable`（主）、`yjwx-save-previous`（备份）永远不变；新增字段必须有默认值，旧档必须能读。
4. **同一时间只有一方改代码**：开工前先 `git pull` 拉最新；做完立刻提交并说明改了哪些文件。
5. **每次发布都要**：改版本号（build.cjs）、在 `src/notice.js` 的 `NOTICES` 最前面加更新公告、更新根目录 `README.md` 的版本说明、同步 `src/tests/wendao.cjs` 里的版本检查。

## 3. 构建、测试、发布

```
npm ci                          # 首次安装（只为测试用的 Playwright）
node src/build.cjs              # 生成根目录 index.html
node src/tests/run.cjs          # 全部测试（需要 Chromium；可设 PLAYWRIGHT_EXECUTABLE_PATH）
node src/package-offline.cjs    # 离线 zip（含 assets/）
```

发布检查：构建无报错 → 全部测试通过 → 手机尺寸实际看一眼 → 提交 → 等 GitHub Pages 部署完成后打开线上地址确认首页版本号。

## 5. 当前玩法规则（以此为准，旧文档中的说法如有冲突以这里为准）

- **一局**：三章（青竹林、古战场、幽冥鬼域），每章三选一路线，章末妖王；第三章击败鬼王通关。
- **主修 10 种 + 副业 6 种**；**只能装备本职业兵器**（硬限制，本命兵器伤害 +25%）。驭兽师、傀儡师为纯召唤。
- **技能**：各职业主动技能池互不重叠（ver7 技能树），心法按职业前缀区分。
- **召唤数量**：青狼、火鸦、木傀、机关蛛、蛊虫每重 +1；统御每重 +1（最多 3 重）。
- **轻功**：初始 1 次、无敌 0.10 秒、距离 110、回复 3.2 秒；金丹、化神各 +1 次；上限 3 次 / 0.30 秒 / 140 / 2.0 秒。仙品、神品云履与轮回殿「凌波」可提升。数值在 `qgStats()`。
- **轻功联动**：10 个职业各有一种，学会核心技能后激活（`DASH_ARTS`）；云履词条穿影、焰踪、护体、回风（`DASH_FX`）。
- **鸣钟**：F 键提前迎战；每提前 1 秒得灵石、叠战意（最多 5 层，伤害 +5% / 修为 +8%）。G 键「引妖」：本关妖物翻倍。
- **开局宗门**：青云剑宗、天符宗、金刚寺默认开放，其余在轮回殿解锁（`V161.freeSects`）。
- **防误点**：属性加点先选后「确认加点」；离开坊市、放弃此世弹确认框（`askConfirm`）。有未用研习点时出发：首次强制打开技能树（`META.treeGuided`），之后提醒（`RUN.treeRemindOff` 本世关闭）。
- **杂兵与兽潮**：在原刷怪之外追加成群杂兵（血 ×0.55、伤 ×0.7、修为 ×0.5），比例按难度与章节（从容 30/60/80%，标准 20/45/60%，劫数 15%）；兽潮外圈加一圈杂兵，单波上限 70；流畅模式减半。数值在 `src/v161.js` 的 `V161`。
- **流派共鸣**：主动技能分锋 / 域 / 控 / 护 / 灵（`FLOW_OF`）。同流派 ≥3 →单修专精（4 个或总重数 ≥12 →大成），≥3 种流派 →混搭三才（4 种→四象），可同时成立。加成写进 `recalc`，招牌效果按斩妖数触发（`FLOW_SPEC`、`FLOW_MIX`）。新增主动技能时要在 `FLOW_OF` 里归类。
- **视角与性能**：电脑（`pointer: fine`）视野短边约 600 逻辑像素，画布像素上限约 240 万（`VIEW`，在 v161.js 包装 `resize`，W/H 是逻辑尺寸）。灵气结晶不用 shadowBlur（build.cjs 替换）。屏幕外首领 / 精英显示边缘箭头。
- **主动大招**：每个主修一个（`ULTS`），Q 键 / 手机按钮，冷却 40 秒（受冷却缩减，最低 24），开战 8 秒可用，无敌 0.6 秒。新增主修时要补一条。
- **首领限时**：现身后计时，超时狂暴，限时内击杀得速斩赏（`V162.bossLimit` 等）。**引妖**最多 20 层（`LURE20`：每层妖物 +20%，血 +8%、伤 +6%、速 +2%；5 层精英、10 层头领与额外装备、15 层轮回点）。**炼器师**上限 +8。坊市固定有研习玉简，另随机洗髓丹 / 精元丹。悟性修为加成递减。标准难度第二、三章妖物额外强化，终局妖王血量 ×1.35。
- **难度**：从容（妖物血 ×0.65、伤害 ×0.6、轮回点减半，前 3 世默认）、标准、劫数（0~5）。
- **剧情**：主线「失落的守门人」+ 问道篇因果系统。核心设定：主角会轮回，是因为魂火被旧阵回收；师父当守门人是为了让主角不再被回收。7 片记忆、6 位故人各 3 段往事（目前写到第 2 段）、7 条暗线（目前完成「第四笔」「无名碑」）。
- **配乐**：10 首，Suno 免费版生成，**仅限非商业用途**；商业化前必须替换。
