# 御剑问仙 · 山海纪

可直接在浏览器玩的修仙肉鸽游戏。新版在原版基础上加入大地图、地域奇遇、迅行战斗、心法重配和可迁移存档。

**[进入游戏](https://kyanionlee.github.io/xiuxian1/)**

## 开始游玩

在线直接打开上面的链接；离线下载 `index.html` 后用浏览器打开即可。美术已嵌入单文件，不需要安装、构建或额外下载素材。

- 电脑：WASD / 方向键移动，自动攻击；F 提前迎战；P / Esc 暂停；B 打开行囊。
- 手机：按住战场拖动移动。右下角“鸣钟”提前迎战，右上角暂停后换装备或调整心法。
- 迅行模式默认开启，可在地图切换；设置对下一场战斗生效。

## 本版内容

- 三个地域，每章 32 个可选节点与 12 层路线。
- 36 个地域奇遇，包含抉择、迎战、交易与问道；21 个小游戏已替换。
- 山水主视觉、主要角色与妖物美术、重新设计的界面。
- 战斗定时存档、暂停保存、JSON 备份与压缩存档码。
- 三轮兽潮通关、提前召唤兽潮和首领。
- 暂停换装，心法卸下、收纳与替换；已学重数在本轮回保留。
- 属性叠加收益递减、持续治疗限额、首领抗爆发和走位预警。

## 存档与更新

战斗每 5 秒及暂停时保存；完成节点回到地图后保存。商店和奇遇请操作完并返回地图，以提交本次收获。战斗中的升级、奇遇或结算界面中途关闭，将回到最近一次战斗记录。

**微信、换设备或清理浏览器数据前，请在“存档与恢复”中复制存档码到游戏外，或下载 JSON 备份。** 固定网址有助于保持浏览器存储位置一致，但本版没有账号云存档，不能保证清理数据后仍然保留进度。

存档键 `yjwx-save-stable` 长期保持稳定；当前格式为 `yjwx-shanhai / schema 1`，兼容读取原版 v4 存档。未来更新应保留兼容读取并提供格式迁移，避免随版本号更换存储键。更新前备份仍然必要。

详细玩法和验证范围见 [使用说明](guide.txt)，生成美术的说明见 [美术与维护](art-and-maintenance.md)。
